## Objective

Download 10 labelled images and apply a CNN to the original images. Then apply **scaling, rotation, and translation** to create a transformed dataset, train the same CNN on the transformed dataset, compare both results, and interpret the effect of geometric data augmentation.

## Dataset

The notebook uses a small **CIFAR-10 subset** with **10 labelled images — one image from each class**:

- airplane
- automobile
- bird
- cat
- deer
- dog
- frog
- horse
- ship
- truck

For validation, 2 different images per class are selected, giving **20 validation images**.

## CNN Architecture

The same CNN architecture is used for both experiments:

1. Conv2D — 32 filters, 3×3, ReLU
2. Batch Normalization
3. Max Pooling
4. Conv2D — 64 filters, 3×3, ReLU
5. Batch Normalization
6. Max Pooling
7. Conv2D — 128 filters, 3×3, ReLU
8. Batch Normalization
9. Global Average Pooling
10. Dense — 64 neurons, ReLU
11. Dropout — 0.3
12. Dense — 10 classes, Softmax

**Optimizer:** Adam  
**Loss:** Sparse Categorical Crossentropy  
**Epochs:** 30

## Geometric Transformations

The transformation pipeline uses:

- **Rotation:** up to 30°
- **Translation:** width and height shift up to 20%
- **Scaling:** zoom range of 25%
- **Fill mode:** nearest

For each of the 10 original images, 20 transformed variants are generated.

Therefore:

**10 original images + 200 transformed images = 210 training images**

## Experiments

### Experiment 1 — Original Dataset

The CNN is trained using only the original 10 labelled images.

Because there is only one image per class, the model can memorize the training examples and may show a large difference between training and validation performance.

### Experiment 2 — Transformed Dataset

The same CNN is trained using the 210-image transformed dataset.

The additional variations expose the CNN to changes in scale, rotation, and position and are intended to improve generalization.

## Results

The `results/` folder contains visual result files corresponding to the notebook:

## Interpretation

According to the assignment design, the transformed dataset is expected to produce more stable validation performance and reduce overfitting compared with training on only the original 10 images.

The key idea is that geometric transformations act as data augmentation. They provide different views of the same labelled examples and encourage the CNN to learn features that are less dependent on the exact scale, rotation, or position of an image.

## Conclusion

This assignment demonstrates how scaling, rotation, and translation can expand a very small labelled dataset and help a CNN generalize better. The comparison between the original and transformed datasets shows why data augmentation is useful when the available labelled data is limited.
